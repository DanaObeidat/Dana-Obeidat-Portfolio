## Overview

Carbon Footprint MRV is a project for structuring institutional Scope 1 and Scope 2 emissions reporting around traceable evidence, controlled calculations and clearly assigned review responsibilities.

The project combines system architecture, governance documentation and a functional software prototype using synthetic organisational data.

Its central design question is:

**When should a calculated emissions value become eligible for reporting?**

## Evidence-to-Reporting Workflow

The designed workflow connects:

1. Organisation, site and reporting-period setup.
2. Activity records and supporting evidence.
3. Emission-factor selection and version references.
4. Emissions calculations.
5. QA/QC review and exception handling.
6. Authorised approval.
7. Reporting-ready records and traceable outputs.

The design distinguishes calculated values from values that have passed the required reporting controls.

## Demonstration Scenarios

The synthetic dataset includes scenarios for reviewing:

- Missing supporting evidence.
- Estimated activity data.
- An unapproved emission-factor version.
- Potential duplicate evidence use.
- Records that meet reporting-readiness conditions.

These scenarios support evaluation of the controls and their expected behaviour.
