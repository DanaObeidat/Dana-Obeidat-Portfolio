# Environmental Data Analysis

**Power BI | Environmental Data Analytics | Data Visualization**

## Project Overview

An exploratory data analysis project examining environmental indicators across countries and over time, using interactive Power BI visualizations.

The project explores CO₂ emissions, climate risk, forest indicators, urbanisation, and waste generation to identify patterns, trends, and relationships in the available dataset.

## Analytical Sections

1. **Environmental KPIs** — Overview of key environmental indicators.
2. **Temporal Analysis** — Trends and changes across years.
3. **Global Climate Risk Overview** — Comparison of climate risk indicators across countries.
4. **Forest & Risk Correlation** — Exploration of relationships between forest indicators and environmental risk.
5. **Urbanisation & Waste Impact Analysis** — Comparison of urbanisation rates and waste generation.
6. **Final Dashboard** — Consolidated interactive overview of the analysis.
