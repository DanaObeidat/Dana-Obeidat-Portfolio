# Dana Obeidat
## Project Strategy & Sustainability Portfolio

I develop project concepts that connect environmental challenges with structured plans for delivery, governance and performance measurement.

This portfolio presents selected independent work in sustainability, circular economy, water, carbon measurement, reporting and verification (MRV), and geospatial risk.

My focus includes:
- Research and problem definition
- Project concept development
- Operational workflows and governance
- Stakeholder mapping
- Pilot planning and performance indicators

The materials are shared as professional work samples. Each project’s stage, assumptions and validation needs are identified in its documentation.
